## ⚡ Quick Start (3 Passos)

### 1️⃣ Descompacte

**macOS / Linux:**
```bash
tar -xzf osceia-design.tar.gz
cd osceia-design
```

**Windows:**
```bash
# Use seu gerenciador de arquivos ou:
# PowerShell
tar -xzf osceia-design.zip
cd osceia-design
```

### 2️⃣ Execute o Instalador

**macOS / Linux:**
```bash
bash install-osceia-design.sh
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy Bypass -File install-osceia-design.ps1
```

### 3️⃣ Reinicie Seu IDE

- Claude Code
- Cursor
- GitHub Copilot
- Ou outra ferramenta com suporte a skills

---

## ✅ Pronto!

No seu IDE, procure por `/osceia-design`:


## 🎯 Seus Primeiros Comandos

Após instalar, tente:

```
/osceia-design init                    # Setup projeto
/osceia-design component LoginForm     # Novo componente Angular
/osceia-design audit                   # Auditar projeto
/osceia-design document boletim        # Gerar boletim Word
/osceia-design bpmn contratacao        # Mapear processo BPMN
```
