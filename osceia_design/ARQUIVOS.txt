🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Descompacte o arquivo (tar.gz ou zip)
2. Entre na pasta: cd osceia-design
3. Execute o instalador:
   - macOS/Linux: bash install-osceia-design.sh
   - Windows:     powershell -ExecutionPolicy Bypass -File install-osceia-design.ps1
4. Reinicie seu IDE (Claude Code, Cursor, GitHub Copilot)
5. Digite /osceia-design no seu IDE
