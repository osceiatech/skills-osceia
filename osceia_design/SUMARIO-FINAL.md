
**Windows:**
```bash
# Use seu gerenciador de arquivos ou PowerShell
```

### 2. Execute o Instalador

**macOS/Linux:**
```bash

bash install-osceia-design.sh
```

**Windows (PowerShell):**
```powershell
cd osceia-design
powershell -ExecutionPolicy Bypass -File install-osceia-design.ps1
```

## 💡 Primeiros Comandos

Depois de instalar, teste no seu IDE:

```

```

Escolha o tipo de projeto:
- **app** → Sistema web (Angular)
- **documento** → Word/PDF (boletins)
- **processo** → BPMN (fluxos)

Depois, experimente:
